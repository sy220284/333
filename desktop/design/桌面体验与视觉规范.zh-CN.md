# 摇摇车桌面 UI：cc-haha 结构替换后的设计真值

> 生效范围：PR19 桌面客户端（React / Electron）。2026-11-07 起采用用户提供的 cc-haha UI 所确立的项目侧栏、会话标签与纸墨主题。保留 333 自有协议、业务与权限流。
> 版权与使用边界：cc-haha 现行社区源码许可证限制商业用途。本仓本轮对用户可见的外层布局与颜色变量进行独立适配，未复制该项目完整业务模块或资源。直接分发其源代码时需要单独遵守原许可证及署名要求。

## 当前界面布局

```text
┌─ 左：项目与会话侧栏 ─┬─ 上：真实会话标签 / 当前工作区标签 ─────────┐
│ 品牌 · 本地项目切换     │ 新会话 | 会话A | 会话B | 当前工具页         │
│ + 发起新会话          ├───────────────────────────────────────────┤
│ 最近会话（可恢复）     │ 工作台内容：AI对话、文件、智能体、任务簿等 │
│ 工作：概览/对话/历史   │ 右侧：实时上下文（可隐藏）                 │
│ 协作：智能体/长期任务  │ 底部：本地执行状态                         │
│ 开发：文件/GitHub      │                                           │
│ 扩展：模型/技能/设置   │                                           │
└─────────────────────┴───────────────────────────────────────────┘
```

侧栏最近会话根据 `sessions.list` 展示，恢复时调用 `sessions.ensureOpen` 和 `sessions.history`。同一 SDK 会话切换到已有标签，不再多次开启执行实例。新建会话需主动点击，任务簿的队列运行、审核和恢复仍需要授权。Ctrl/Cmd+K 的全局入口保留全部十页。

## 十类真实功能页面

1. 概览：以新任务作为首要操作，展示本地会话、任务与模型快照。
2. AI 对话：SDK 消息、实时流、模型切换、停止与工具审批。
3. 历史记录：本地会话检索与继续，恢复由 SDK 处理。
4. 智能体团队：主子智能体与 Super Agents 双模式、成员状态。
5. 长期任务：Mission、工作项、队列、人工审核、失败恢复。
6. 项目文件：文件树、编辑与本地 Git 差异。
7. GitHub：工作区 Git 状态及 333 自有审查流程。远端 PR/CI 的直接 UI 连接按真实 API 补齐。
8. 模型管理：多模型目录、凭据、权限和选用。
9. 技能与 MCP：本机服务列表、启停/增删以及能力接入。
10. 设置：六主题、动效、面板、并发审批和本地 Host 状态。

## 原 cc-haha 页面入口决策

**保留并映射**：项目导航、会话标签、对话排版、权限对话框、文件浏览/差异、智能体团队、扩展、设置。

**根据 333 重构**：模型与 OAuth 入口、工具调用和会话转发、长期任务工作项、GitHub 审查、历史续接、安装与本地数据保存。

**从 333 新 UI 剔除**：原 cc-haha 独立服务端路由、云端/远程配对、宠物窗口、飞书/钉钉/QQ 适配器、其特有的付费/市场和模型凭据管理、尚无后端契约的语音、浏览器和终端独立服务页面，以及未获明确要求的定时任务入口。

如以后明确新增同类能力，应先为 333 接通专用协议和权限模型，再加入口，避免视觉按钮与实际功能脱节。

## 架构与组件

- 渲染：`desktop/src/App.tsx` 负责页面组合及原有事件处理。
- 色系与外壳：`desktop/src/cc-haha-theme.css`，覆盖原视觉系统。旧 `styles.css` 暂保留消息布局和任务/文件/审批等功能组件的基础样式，不能直接删除导致功能不可用；后续只在视觉新组件接通后逐步删除无引用规则。
- 通信：`desktop/electron/preload.ts` 提供白名单 IPC，`desktop/electron/main.ts` 调用 `desktopHost`。始终遵守信任边界和按会话审批。
- 业务：`src/services/desktop/gateway.ts` 与 SDK 原生流负责会话、Agent、任务、模型及权限。
- 外部源设计与许可：<https://github.com/NanmiCoder/cc-haha>。
