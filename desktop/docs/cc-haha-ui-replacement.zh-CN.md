# cc-haha 桌面界面替换 333：落地范围及接口核对

## 基线与原则
- 目标分支：PR19 `integration/333-independent-pr16-pr18-20261106`，来源为用户上传的 `cc-haha-main.zip`。
- 已在源码里替换：旧版固定十项大菜单和顶部面包屑，调整为 cc-haha 风格的项目侧栏、最近会话、分组功能入口及会话/工作区标签栏；把旧蓝紫色渐变和仪表盘装饰改为纸墨主题、新任务起点和中性卡片。提供浅色纸墨与墨夜主题。
- 业务事实以 333 `desktopHost` 的 JSON Lines 协议为准；不将原项目的服务端、设备连接、云同步、模型路由或授权体系带进来。已有的 333 十类页面功能继续可访问。
- 参考来源：<https://github.com/NanmiCoder/cc-haha>，上传压缩包带有 `cc-haha Community Source License 1.0`。本次新主题与布局为适应 333 独立编写；若将原项目源文件/资源直接再分发，须评估并遵守其非商业与署名条款，商业用途需原权利人授权。

## 页面逐项决策
| cc-haha 界面或入口 | 333 对应 | 决策 | 实施范围 |
| --- | --- | --- | --- |
| 项目与会话侧栏、项目切换 | `workspace.pick`、`sessions.list`、`sessions.ensureOpen` | 保留并替换 | 最近会话直接真实恢复，切换目录保留工作区隔离 |
| 顶部多会话标签与布局 | 当前会话、十个路由页面 | 改造 | 用真实导航标签替换面包屑；后续多 SDK 并行标签必须加入会话归属和释放策略 |
| 新任务首页、消息流、输入框 | `sessions.open/send/interrupt` | 保留并改造 | 先保留 SDK 流式消息与权限弹窗；首页取消原 333 的宣传装饰 |
| 终端、文件树、编辑器、差异审查 | `workspace.list/read/write/gitStatus/gitDiff` | 保留并加强 | 继续使用本地受限文件与 Git 接口；可在此基础上扩展终端流 |
| 子智能体、Agent Teams / 工作流 | `agents.overview/members`、`tasks.*`、`missions.*` | 改造 | UI 需要突出任务成员、审核/停止/恢复/队列，沿用双模式授权语义 |
| 定时任务、日程提醒 | 333 本地 Mission 为手动执行 | 剔除 | 用户未要求定时能力；不创建隐含计划任务 |
| 远程访问、H5 服务、二维码配对 | 333 只接受本地可信桌面 Host | 剔除 | 避免把本地权限面暴露到网络 |
| 飞书/钉钉/QQ 适配器 | 333 无等价集成契约 | 剔除 | 暂不展示不可用入口 |
| 宠物悬浮窗和素材 | 333 无对应业务价值和运行接口 | 剔除 | 不迁入额外进程及资源 |
| 语音听写、语音修正 | 333 尚无独立完整桌面协议 | 待独立实现 | 当前 UI 不显示没有后端的语音按钮 |
| 插件市场/第三方账号和 OAuth | 333 自有插件/MCP/模型凭据体系 | 改造 | 使用 `mcp.list/add/toggle/remove`、333 模型凭据 API，保留本地权限检查 |
| 模型配置 | 多服务商发现、OAuth/API Key | 改造 | 由真实后端返回；不继承 cc-haha 提供商固定映射或旧凭据目录 |
| 长期任务 | Mission 任务簿、工作项队列与审批 | 补充 cc-haha 界面 | 任务创建/选择、队列执行、停止、人工审核与失败恢复不可丢失 |
| GitHub 工作台 | 333 `/github` 与本地 Git 接口 | 加强 333 专有入口 | 将仓库配置、PR 审查、CI 运行、原生评论等实际接口接到统一 UI，不拿本地 Git 冒充远程 GitHub |
| Token 使用与诊断 | SDK 消息、模型用量、实际记录 | 逐项接入 | 显示实际事件与用量，缺少实时数据的字段不做模拟 |
| 系统设置、主题与权限 | 333 `permissions.*`、`host.*` | 保留并适配 | 异步权限按会话隔离，主题保存在本机 |

## 技术结构
- `desktop/src/App.tsx`：继续保留 SDK 事件处理、会话、任务、审批和十页功能主体，替换外层导航结构和启动主视觉；项目与会话入口直接调用已有业务。
- `desktop/src/cc-haha-theme.css`：新的纸墨/墨夜主题、分组侧栏、顶部标签、卡片和动态状态；`main.tsx` 在原业务样式后引入，逐步消除旧视觉样式。
- `desktop/electron/main.ts`、`preload.ts`、`src/services/desktop/*`：不修改，保持已验收的可信 IPC、进程隔离和 SDK 原生能力。

## 当前变更边界
本次修改完整切换桌面工作台外层交互与视觉主题，页面内部仍调用 333 原有实际执行组件；独立 cc-haha 插件市场、远程接入、移动版及服务端没有进入代码库。本报告列出下一步深层页面改造和端到端验收，不以初步视觉替换冒称所有 UI 功能已移植。

## 新会话首页整页替换
原 333 Dashboard 的四指标仪表盘、旧渐变展示块和「快捷入口」指标卡片已从组件树移除。采用 cc-haha 的新会话起点：居中的项目上下文、新会话大入口、四种真实可填入提示词的快捷任务、最近会话和 333 本地任务簿。所有快捷操作进入既有消息发送或会话恢复路径。新增完整 React 测试验证从首页快捷任务进入会话并发送 SDK 消息。
