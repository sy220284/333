## 升级工作顺序

1. **从最新版定位函数**：读取 2.1.317 反编译模块和资源，确认真正的入口、默认参数、状态变化、权限与异常路径。
2. **检查 PR #7 当前实现**：对照入口、工具/SDK、上下游调用和实际行为。已有且相同的保留；不同的调整；没有的标记待实现。
3. **优先移植，缺失重写**：可直接移植的函数、依赖和资源先移植；缺失源码的功能按照官方 x64 安装程序真实执行结果还原逻辑，接通每个实际消费者。
4. **直接测试、继续修复**：运行必要的功能测试、场景回归、原版/候选版行为比较和三平台构建（适用时），修正差异后才计入完成。无需额外日志报表、人工签收或多层证明流程。

## 已确认的 PR #7 重点差异

- 原版 CLI 顶层18个子命令；当前 `src/main.tsx` 缺少 `gateway`、`purge`、`ultrareview` 的直接注册。
- 插件原版有 `details`、`eval`、`prune`、`tag`、`test` 等子命令，当前 CLI 入口未齐。
- 插件安装仍需补齐 `--accept-command` 哈希授权及 `.mcpb` 服务级配置语义；不能仅增加参数。
- 需要逐条对齐新插件 `ui.place`、`ui.backdrop`、`prompt.paint`、嵌套 session ID、MCP 任务开关及企业网关行为。
- 官方资源部分此前已逐字节一致，但主 CLI 与跨宿主运行仍有缺口，继续直接修复代码。
