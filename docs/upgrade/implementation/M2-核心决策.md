## 本轮实际推进

- 新移植/重写的普通模块使用 `.ts`，界面使用 `.tsx`，补齐实际类型并接入生产消费者；仓库根目录 `AGENTS.md` 已固化该要求。
- C01：目录接通家族别名、provider配置、原生1M身份、显示和价格；按模型effort配置进入请求，选择器及`/effort`按模型保存；同步长提示、1小时缓存、US区域和fast费用计算。
- C02：按原版移植文本文档、JSON密度、嵌套文档和搜索结果的占用计算，API上下文统计与微压缩共用；Read保留和压缩禁用筛选补齐TS类型。
- C04：按原版保持会话围栏启用状态，设置重载不会解除已启用限制；写围栏限制工作树工具，接通规则收集和显示。修复附加目录来源丢失造成的越界：项目设置中的目录不再变成CLI授权，显式CLI授权保留。实际Read/Edit进程覆盖项目目录、读取例外、符号链接和目录外写入。
- 验证入口：`npm run test:m2`。提供`CLAUDE_CODE_317_REFERENCE=/绝对路径/claude`可同时执行原版x64对照；三平台重建工作流已接入，Linux使用锁定SHA的317程序。
- 原版2,924模块与二进制原始字节已重新核验；模型身份2,600组函数对照无差异。本轮核实的调用链按下列工作包继续记录，未覆盖的分支保持进行中。
