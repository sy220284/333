# M5｜第 4 层：扩展能力

**目标版本**：Claude Code 2.1.317。**范围**：技能及官方资源、插件和市场、MCP/认证、Monitor/Workflow/调度、附件/PDF/Artifact。
**负责链路**：C08、C09、C10、C17、C18（5 条，覆盖此层所有发现的新版入口、函数、事件与消费者；旧 102 功能仅用于回归下限）。
**依赖层**：M2、M3、M4。

## 对齐与改造原则

每条链均从官方 2.1.317 取证，识别真正入口、函数、数据契约、权限/环境条件、执行副作用、状态生命周期、终端和异常行为。优先直接移植原版可读 JS/资源及依赖；无法移植时要追踪调用链并复测官方 x64 安装包，在真实运行结果支持下按语义重写；重写后替代旧实现，清理已失效分支和过渡代码。每个修复必须验证上下游消费者，不能以函数名存在或通过单元测试替代完整实现。

本卡纳入全部适用的正式 2.1.317 能力，以下已有功能编号仅用来保护历史回归覆盖率；发现本卡的新能力立即扩展同一链及测试，不另起碎片清单。

## 本层专项核查

1. 对照官方版本复原技能/插件/MCP 的发现、缓存、加载、权限、配置、同步、安装及清理流程。
2. 对 Monitor/loop/Workflow/附件和 Artifact，追踪任务状态、真实事件、停止与恢复，核查使用者和宿主接口。
3. 逐项验证插件损坏及迁移、认证撤销、MCP 拒绝/复连、PDF/附件读取或上传、原生技能资源字节一致与自动化状态。

1. 本卡所有功能链均有经核实的最新版函数语义、实际源码实现与可达入口；历史旧入口、同功能重复实现和权限兼容已经核对替换或正确退场。

3. 交付所有修改的源码、资源原件/映射、单测与集成测试、独立构建、三平台适用回归、官方 x64 同场景对照、真实差分、CI 和人工复核记录。
