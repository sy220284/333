## 直接对齐方式

逐条读取官方2.1.317真实函数和资源，检查PR #7的调用者、输入输出、权限和错误处理。能移植就直接移植；缺失则按官方x64实际行为重写；完成后直接运行适用功能与场景测试。

1. 对照官方 Linux x64 的 TTY/键鼠/屏幕阅读器/动画及跨平台桌面入口的用户可见输出。
