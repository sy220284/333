# M6｜第 5 层：用户和云端

**目标版本**：Claude Code 2.1.317。**范围**：终端UI/无障碍/动效、IDE、Remote Control、企业云及自建Runner、Slack/Code Review外部服务。
**负责链路**：C12、C13、C14、C15、C20（5 条，覆盖此层所有发现的新版入口、函数、事件与消费者；旧 102 功能仅用于回归下限）。
**依赖层**：M2、M3、M4、M5。

## 对齐与改造原则

每条链均从官方 2.1.317 取证，识别真正入口、函数、数据契约、权限/环境条件、执行副作用、状态生命周期、终端和异常行为。优先直接移植原版可读 JS/资源及依赖；无法移植时要追踪调用链并复测官方 x64 安装包，在真实运行结果支持下按语义重写；重写后替代旧实现，清理已失效分支和过渡代码。每个修复必须验证上下游消费者，不能以函数名存在或通过单元测试替代完整实现。

本卡纳入全部适用的正式 2.1.317 能力，以下已有功能编号仅用来保护历史回归覆盖率；发现本卡的新能力立即扩展同一链及测试，不另起碎片清单。

## 本层专项核查

1. 对照官方 Linux x64 的 TTY/键鼠/屏幕阅读器/动画及跨平台桌面入口的用户可见输出。
2. 核对 IDE/Remote Control/企业云/自建 Runner/Slack/Code Review 的宿主与服务端协议、身份、审批、重试、取消及故障回收。
3. 涉及外部宿主和远端服务器时必须补真实连接或可核验的服务端/扩展原始证据，模拟只能覆盖本地链路，保持待核直到跨端验收。
