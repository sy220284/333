# M3｜第 2 层：执行能力

**目标版本**：Claude Code 2.1.317。**范围**：文件与命令工具、Hooks/SDK与控制事件、CLI协议、认证/网络/TLS/遥测。
**负责链路**：C03、C06、C11、C16（4 条，覆盖此层所有发现的新版入口、函数、事件与消费者；旧 102 功能仅用于回归下限）。
**依赖层**：M1、M2。

## 对齐与改造原则

每条链均从官方 2.1.317 取证，识别真正入口、函数、数据契约、权限/环境条件、执行副作用、状态生命周期、终端和异常行为。优先直接移植原版可读 JS/资源及依赖；无法移植时要追踪调用链并复测官方 x64 安装包，在真实运行结果支持下按语义重写；重写后替代旧实现，清理已失效分支和过渡代码。每个修复必须验证上下游消费者，不能以函数名存在或通过单元测试替代完整实现。

本卡纳入全部适用的正式 2.1.317 能力，以下已有功能编号仅用来保护历史回归覆盖率；发现本卡的新能力立即扩展同一链及测试，不另起碎片清单。

## 本层专项核查

1. 逐个核对工具 schema、事件结构、Hook 顺序、SDK 流式协议、CLI 参数/错误码、网络重试副作用。
2. 优先替换为新版工具真实执行器及协议转换，核对超时、取消、重复发送、并发、部分成功后的安全恢复。
3. 覆盖文件真实读写、PowerShell/Bash、Notebook、多路径/软链、HTTP 429/529/TLS/证书、CLI 输出字节和退出码。

## 本卡完成门槛

1. 本卡所有功能链均有经核实的最新版函数语义、实际源码实现与可达入口；历史旧入口、同功能重复实现和权限兼容已经核对替换或正确退场。
2. 每个链路至少覆盖正常执行与拒绝/失败、取消/超时、持久化/恢复（适用时），并证明输出、事件、资源或副作用与原版一致。对外部服务必须补对应宿主或服务端原始证据。
3. 交付所有修改的源码、资源原件/映射、单测与集成测试、独立构建、三平台适用回归、官方 x64 同场景对照、真实差分、CI 和人工复核记录。
4. 本层依赖层的真实验收均已完成，且本卡功能在上层使用场景中未退化。未达到其中任一条件则保持待核，持续落实缺口直至闭环。
