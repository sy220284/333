# M1｜第 0 层：构建基础

**目标版本**：Claude Code 2.1.317。**范围**：官方资源、依赖、原生扩展、启动、独立构建和三平台发行。
**负责链路**：C19（1 条，覆盖此层所有发现的新版入口、函数、事件与消费者；旧 102 功能仅用于回归下限）。
**依赖层**：无。

## 对齐与改造原则

每条链均从官方 2.1.317 取证，识别真正入口、函数、数据契约、权限/环境条件、执行副作用、状态生命周期、终端和异常行为。优先直接移植原版可读 JS/资源及依赖；无法移植时要追踪调用链并复测官方 x64 安装包，在真实运行结果支持下按语义重写；重写后替代旧实现，清理已失效分支和过渡代码。每个修复必须验证上下游消费者，不能以函数名存在或通过单元测试替代完整实现。

本卡纳入全部适用的正式 2.1.317 能力，以下已有功能编号仅用来保护历史回归覆盖率；发现本卡的新能力立即扩展同一链及测试，不另起碎片清单。

## 本层专项核查

1. 核对官方 2.1.317 Linux x64 安装包、反编译模块、内置资源及原生二进制的哈希、来源和加载位置。
2. 优先移植官方源码、技能/插件原版资源和启动依赖，修正构建/恢复/发行路径，确保官方发布产物可在相同平台复现。
3. 在 Linux/macOS/Windows 构建后运行 CLI/资源校验、发行包自包含、原生模块加载、依赖版本锁定、干净环境启动、性能/异常路径验证。
