# M4｜第 3 层：任务运行

**目标版本**：Claude Code 2.1.317。
**改造范围**：Agent/团队/后台任务与消息、会话保存/恢复/身份隔离。
**功能链**：C05、C07；本卡拆分 10 个初始工作包。
**前置层**：M2、M3。
**实现状态**：进行中；本次更新任务范围与拆分，不把已有专项通过改写为整卡完成。

## 本卡执行要求

1. 以旧仓库实际生产调用链为改造对象，先定位新版入口、导入依赖、核心函数和全部消费者，再逐函数比较。
2. 对齐参数名称/类型/必填与可选/缺省及null语义、配置来源和优先级、功能开关、返回结构、事件顺序及错误码。
3. 对齐状态转移、权限、并发、超时、取消、重试、幂等、副作用、持久化和恢复；保留新版的能力启用和宿主条件。
4. 优先移植完整职责模块及依赖；有耦合则按职责拆分再接回生产调用链；缺失或不适配的实现按原版代码和x64行为重写。
5. 同包同步更新调用方/被调用方、组件、素材、提示词、技能、插件、接口schema、SDK类型、原生依赖及构建发行资源。
6. 已有且逐函数一致的代码保留；已完成专项沿用对应提交和测试，只补剩余差异。废弃逻辑按新版生命周期删除并同步迁移消费者。
7. 每包直接运行适用的功能与原版对照测试，覆盖成功、边界、错误、取消及恢复；只改入口、类型、开关或名称不足以完成工作包。
8. 当前137功能/137场景是已有回归范围，100个工作包是本轮拆分；新版调用链中新发现的函数、资源和能力继续纳入，不以这些数量限制升级范围。

原版位置以下以 `04_逐模块可阅读JavaScript/` 为默认根；资源目录单独列出。它们是本链已经定位的分析起点，实施时继续沿函数调用、导入和实际消费者展开，不限于列出的文件。

1. 本卡全部功能链和工作包，以及执行中新发现的适用新版能力，均已在仓库实际生产代码中落实。
