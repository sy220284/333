1. 逐条核实 90 种旧开关实际新版终态。仅找到相似字符串不可升格为 `ACCEPTED`。
2. 逐项核实 61 项新版执行路径和成功、失败、取消及恢复；静态锚点不代表调用链。
3. 逐条核实 6,313 更新对目标版本的最终影响及 F 归属或有证据的不适用，并保留确定的最新版路径。
4. 检查 7 个旧版缺失内部模块的目标终态和迁移责任，不用空实现遮蔽缺口。
5. 确认全部机器验证、适用的运行差分及安全负例通过，执行 `node build/m1-verify.mjs --require-closed` 成功后，才允许开始 M2。
