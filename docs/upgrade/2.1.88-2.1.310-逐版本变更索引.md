## 如何利用

1. 从功能台账的 `Fxxx` 出发，寻找本索引中相关版本，再打开该版本官方更新记录逐条读取；不能只按最早出现的版本实现。
2. 将版本动作整理为 `新增 → 改动 → 回退/废弃 → 后续修复 → 2.1.310 最终代码/运行行为` 的连续链。
3. 对有 `Removed/Reverted/Deprecated` 的功能，必须先复核 2.1.310 终态。
4. 需要核对完整英文改动细节时，以[官方 Changelog](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)为准；本文件仅保存统计与版本指针。

**核对结果：180 个版本，6313 个官方条目。**
