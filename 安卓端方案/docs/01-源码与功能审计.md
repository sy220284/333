## 需要避免的错位
- Host Session 的标题和消息记录属于唯一事实源，不在安卓端制造第二套 session 数据库。
- Remote JSON 以生成后的方法描述符为准，参数必须精确：`payload={"args":{"request":...}}`；Host 可拒绝多余字段。
- `session/follow` 的 snapshot + event/assistant-stream 不是普通 SSE 文字拼接；必须按 cursor/revision 去重、排序与重连。
- `session/list` 的 list request 为可空对象，但 payload 必须提供具名 `request` 参数。
- 非 Owner 访问由 Host RemoteAccess 决定，安卓 UI 只能预先解释，实际执行仍以 Host 拒绝/允许结果为准。
- Android Gradle 工程、JNI Node、shell、sandbox 尚需实施与验证；Android 字符串出现在 bundle-platform 中仅表示候选平台名。
