# 开发与验收计划 V1

## 工程与版本
开发基线来自 777 `41b2559f90f0f732799cd17bbd003e8a71cb2020`，仅迁移工具链（Gradle 9.8.1 / AGP 9.4.0 / Kotlin 2.4.20 / JDK >=27 / Android compile 37 / build tools 37.0.0 / Node 26 Android Runtime / Node Host >=24）；不迁移 777 的 Codex 功能及特定包名。333 官方 Host 构建按其 Node >=24.9 + pnpm 规范。所有版本在 `tools/toolchain-versions.env` 锁定并由 CI 审核。

## 开发迭代验收（按依赖顺序在单条工作链连续推进）
A. 合同：检查 333 所有 @Remote 生成描述符、错误/权限/流协议与 SDK；产出机器可查 feature-map。通过条件：每个 UI 动作绑定权威 RPC，覆盖初始/读取/可用/需操作/失败/完成状态。
B. UI：完成 19 个页面、全套基础和业务组件、导航/回退、缩放、暗色、触摸语义、原创 SVG 与动效参数；通过条件：Screenshot、Compose accessibility、无裁剪且读屏顺序合理。
C. 连通：Cookie 握手、调用 id 核对、会话创建/发送/跟随、断线补事件、附件上传、审批转发；通过条件：真实 Harness Host + HTTPS + 网络抖动测试。
D. 本机：Node26 + Host bundle + native addons，Shell/PTY，完整 Session persistence，缺少 runtime 时明确状态；通过条件：安装 APK 后不依赖 PC/服务器完成会话与工具测试。
E. 平台：SAF/后台任务/本地权限/工作区/下载/MCP/插件流程；通过条件：冷启、断网、恢复、回收、升级及权限矩阵。
F. 发布：x86_64 模拟器 + arm64 真机，Android 16/17、16KiB、兼容性、签名升级、安装即用；通过条件：CI 全绿，QA 设备证据和发布产物可追溯。

## 测试
- 静态：`tools/verify-contracts.py` 读取 feature-map/tokens/motion 与必需代码检查。
- 单元：Remote envelope 编码/解码；非法 Origin/协议拒绝；响应 id 与 JSON 错误处理；连接取消。
- 集成：真实 Host 的 create → prompt → follow，foreground/background，错误回放，权限确认/拒绝。
- 设备：Android 16、17；至少 arm64 和 x86_64；系统字体 100/200%，360/411dp，暗色/亮色；横竖屏；低内存与网络切换。
- 安全：Android 非法命令、越权文件、信任域、Cookie 生命周期、ThirdParty/包签名、16KiB ELF。
- 发布：每次发布从已通过 CI 的 SHA 生成 APK；禁止只凭工作流开始或某个 job 成功就写“完成”。

## 完成定义与当前证据
本分支代码属于“实现启动”；缺 Android SDK/JDK27、二进制 Host Runtime/设备验收的环境应明确报告待验证门禁。任何功能展示“已连接”须有真实服务成功回包。路径中 `android-app` 存在和静态测试通过不等于可运行 APK。

## 复用治理
上游 Remote 增改时优先运行接口扫描重建 feature-map，再更新 Kotlin gateway/业务映射；SVG/Token/Compose 从同一语义键映射，禁止同一能力在多个页面写出冲突的请求参数。正式发布前保留准确版本清单、代码 SHA、构建哈希与测试结果。
