## @Remote 方法记录与核验

完整带路径、行号、类、方法与 stream 声明列表见 `contracts/remote-inventory.json`（228 条）。

核验原则：所有使用 `@RemoteScope` 的 Context 身份绑定、参数具名字段、返回 codec、Host Principal 访问控制、source 启动回退，需要在 CI 生成的 Typert descriptor 上再次核对。静态扫描绝不将未标注/未挂载的 Host 服务声明成安卓可用 API。

## 移植工作的决定性依赖

1. 核心 API：`packages/api/gateway`、`packages/api/remotes`、`packages/client/connection`，复用协议并实现 Kotlin 严格 codec。
2. 会话单一数据源：`packages/api/session-controller` 与 `packages/session`，按 snapshot / seq / assistant stream 复原。
3. Android 独立 Host：必须适配 Node Android 可执行文件、native addon、子进程、PTY、工作区文件系统、sandbox 和凭据安全。
4. 工具与插件：MCP stdio HTTP、插件包安装/兼容性、模型工具调用、权限审批、恢复机制需真机验收。
5. UI：把 333 Web 模块当前动作和交互语义映射到 Jetpack Compose，不在安卓端再造 Cordis 业务层。
