# 三月七（March 7th）

一个跑在终端里的 AI 编程助手：你说要做什么，它读代码、改文件、跑命令、提交 PR，全程流式输出、随时打断。支持一套主从智能体协作体系，并正在向多智能体团队协作演进。

本项目是对 Claude Code 2.1.88 发行包的源码级独立重建——从官方 `cli.js.map` 恢复全部 1,902 份 TypeScript 源码后重新构建，功能对齐官方 2.1.317，不依赖官方 `cli.js` 与官方云服务运行。

## 两种工作模式

### 模式一：主从智能体

一个主智能体管理多个子智能体，围绕当前任务完成分工与交付。适合日常工作。

- 主智能体负责理解需求、拆解任务、派发与汇总；子智能体负责执行
- 子智能体按职能分工：只读探索（代码检索与调研）、规划、实施、验证等，各有独立的工具权限边界
- 每个子智能体拥有独立上下文，干完活向主智能体交付报告（完成了什么、改了哪些文件、测试与提交记录）
- 子智能体之间不直接对话，冲突与发现统一上报主智能体裁决，避免互相踩踏
- 长任务可续接：子智能体带着已有上下文恢复工作，不重复劳动

### 模式二：超级智能体（Super Agents）——演进方向

一个持续工作的协调中枢，管理多个具有独立上下文、记忆和任务状态的智能体。成员可以合作，也可以独立处理不同项目。适合大型、长期、多任务工作。

当前代码已具备的地基：

- **团队生命周期**：创建与解散智能体团队，成员各自独立上下文、互不污染
- **成员协作**：跨智能体消息互通，支持本机 socket 直连与跨机会话发现
- **任务状态**：成员任务可暂停、恢复、交接，各自维护任务状态
- **协调中枢**：协调者模式管理 worker 成员，按研究/实施/验证分工，规范并行修改同一分支时的边界与上报纪律

演进方向：让协调中枢长期驻留，主动调度多个长期成员——成员可以分属不同项目、各自积累记忆与任务队列，按需组队或独立作业，把"一次性任务协作"升级为"持续的组织化协作"。

## 功能特性

- **多模型直连**：内置 OpenAI、DeepSeek、Qwen、Kimi、智谱 GLM、MiniMax 直连入口与 ChatGPT 授权登录；按模型代际自动适配推理、采样与输出字段；支持模型能力探测与动态定价
- **交互式终端体验**：REPL 对话、流式渲染、任务进度实时展示、Vim 式键位可自定义
- **全套编程工具**：文件读写与编辑、目录操作、Bash 执行、代码搜索、Web 检索，工具调用全程可见
- **子代理与任务系统**：可派生子代理并行干活；长任务后台执行、断点恢复
- **会话管理**：上下文自动压缩（compact）、会话导出与恢复、成本追踪
- **MCP 接入**：连接 MCP 服务器扩展工具面，支持 elicitation 交互
- **插件与技能**：内置插件包、技能目录、自定义斜杠命令
- **Hook 系统**：在工具调用前后注入自定义脚本，把控关键动作
- **权限边界**：每个敏感操作前请求授权，可按工具粒度配置自动批准规则
- **代码工作流**：分支管理、提交、diff 审阅、PR 自动化（commit / commit-push-pr / autofix-pr 等）
- **诊断能力**：`doctor` 自检、调试工具调用、内存转储、本地诊断

## 构建与安装

环境要求：Node.js、Bun。

```bash
npm install
npm run rebuild    # 资源校验 → 依赖恢复 → Bun 编译 → 独立编译 → 发行打包
```

产物在 `dist/`（`cli.js` 与 `launcher.cjs`）。构建前会校验嵌入资源完整性（SHA-256 台账）与冻结依赖，任何一项不符即中止。

## 快速开始

```bash
node dist/launcher.cjs
```

首次使用按提示配置模型凭据即可开始对话。常用操作：

- 直接输入需求描述，三月七会自行规划、调用工具、逐步完成；复杂任务可直接说"用一组智能体协作完成"
- `/help` 查看全部斜杠命令，`/config` 调整配置，`/cost` 查看开销
- `Esc` 随时打断当前执行
