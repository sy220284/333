<td width="50%" valign="top">

### 🤖 主从智能体

**一个主智能体，多个子智能体，围绕当前任务分工与交付。适合日常工作。**

主智能体理解需求、拆解任务、派发与汇总；子智能体按职能分工——只读探索、规划、实施、验证，各有独立上下文与工具权限边界。

干完活交付报告：做了什么、改了哪些文件、测试与提交记录。冲突不私了，统一上报主智能体裁决。长任务可续接，带着上下文继续干，不重复劳动。

已具备的地基：团队创建与解散、成员独立上下文互不污染、跨智能体消息互通（本机 socket 与跨机发现）、任务暂停 / 恢复 / 交接、并行修改同一分支的边界纪律。

## ✦ 核心能力

**多模型直连** — 内置 OpenAI、DeepSeek、Qwen、Kimi、智谱 GLM、MiniMax 直连入口与 ChatGPT 授权登录；按模型代际自动适配推理、采样与输出字段；模型能力探测、动态定价、令牌计量。

**全套编程工具** — 文件读写编辑、代码检索、Bash / PowerShell / REPL 执行、Notebook 编辑；接入 LSP 语言服务器，支持跳转定义、查找引用等代码智能。

**任务系统** — 任务清单、后台任务、定时调度（cron）、条件监控等待；长任务离开执行，回来收结果。

**会话管理** — 会话恢复、操作回退、上下文自动压缩、成本追踪、会话导出。

**记忆系统** — 跨会话记忆沉淀与提取，会话摘要自动生成，项目上下文越用越熟。

**计划模式** — 先规划后动手：进入计划模式梳理方案，确认后再实施；支持简报模式聚焦输出。

**工作树隔离** — 一键进入独立 git worktree，实验性修改不碰主分支。

**MCP 双向** — 作为客户端接入任意 MCP 服务器扩展工具面；也可作为 MCP 服务端对外暴露能力；支持 MCP 授权与资源读取。

**插件与技能** — 插件包、技能目录、自定义斜杠命令，按需扩展。

**Hook 与权限边界** — 工具调用前后注入自定义脚本；敏感操作逐项授权，可按工具粒度配置自动批准。

**终端体验** — 流式渲染、vim 模式、自定义键位、主题与输出样式、状态栏。

**代码工作流** — 分支管理、提交、diff 审阅、PR 自动化一条龙。

**诊断** — `doctor` 自检、上下文可视化、会话使用分析报告。

## ✦ 快速开始

```bash
npm install
npm run rebuild     # 资源校验 → 依赖恢复 → 编译 → 打包
```

```bash
node dist/launcher.cjs
```

- 直接输入需求描述；复杂任务说一句「用一组智能体协作完成」
- `/help` 查看全部命令 · `/config` 调整配置 · `/cost` 查看开销
- `Esc` 随时打断
